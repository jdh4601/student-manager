## 2. 발표 서사 (말할 내용)

1. **백로그**: PRD 요구사항(REQ-xxx)을 Jira 에픽/스토리로 분해 → 우선순위(Must/Should/Could)로 정렬.
2. **스프린트**: 1~2주 주기. 각 스프린트는 "동작하는 수직 슬라이스" 1개를 완성 (워터폴의 빅뱅 통합 회피).
3. **변화 수용**: v2.1에서 OLAP/AI가 추가되고 Kafka→LISTEN/NOTIFY로 피벗하자 **백로그를 재계획**(ADR-003). 워터폴이었다면 설계 동결로 불가능했을 변경을 애자일로 흡수.
4. **추적성**: 요구사항 → 에픽 → 스토리 → 커밋(conventional) → Jira 완료 전환의 닫힌 루프. CLAUDE.md에 `Transitions 11/21/31` 자동화.
5. **AI 워크플로우와 연결**: Planner Agent가 이 Jira 백로그를 입력으로 Implementation Plan 생성 → 애자일과 AI 워크플로우가 한 파이프라인.
